# 干死狗庄 · 手机版

股票到价提醒 · 条件选股 · 按图找相似。**手机上直接用，不用开电脑。**

---

## 上线（三步，约 3 分钟）

### 1. 建仓库

GitHub 右上角 **+** → **New repository**

- Repository name 填 `gansigouzhuang`（或任意名字）
- 选 **Public**（免费的 Pages 需要公开仓库）
- 勾 **Add a README file**
- 点 **Create repository**

### 2. 传文件

在仓库页面点 **Add file** → **Upload files**，
把本地这 4 个文件拖进去：

```
index.html   stocks.js   industry.js   vision.js
```

> 不要传 `README.md`，仓库里已经有一个了。

拉到底点 **Commit changes**。

### 3. 开启 Pages

仓库 **Settings** → 左侧 **Pages**

- Source 选 **Deploy from a branch**
- Branch 选 **main**，文件夹选 **/ (root)**
- 点 **Save**

等 1~2 分钟刷新页面，顶部会出现网址：

```
https://你的用户名.github.io/gansigouzhuang/
```

**这个网址就是你的 App。**

## 装到手机上

1. iPhone / iPad 用 **Safari** 打开上面的网址
2. 点底部 **分享** 按钮 → **添加到主屏幕**
3. 起个名字 → 添加

以后点主屏幕上的图标就能用，全屏打开，没有地址栏，跟原生 App 一样。

> 必须用 Safari 才能「添加到主屏幕」，Chrome 不行。

---

## 它能干什么

| 功能 | 说明 |
|---|---|
| **添加提醒** | 输入代码 / 名称 / 拼音首字母（`600519`、`茅台`、`gzmt`），保存 |
| **条件选股** | 「市盈率低于10的银行股」这类大白话，扫全市场，结果标 √ |
| **按图找相似** | 丢一张 K 线截图，找形态像的股票 |
| **看行情** | 每条提醒都显示实时价格 |

---

## 它不能干什么（重要）

**它自己不会盯盘，不会给你发通知。**

这不是偷懒，是浏览器的硬性限制：**手机一关屏，页面里的 JavaScript 就停了**。
任何纯网页都做不到在后台定时检查行情。

想收到到价提醒，需要一个「一直醒着」的东西在查行情 —— 那就是**桌面版**
（在电脑上跑，每 20 秒查一次，到价了推到 Bark，你手机上就收到通知）。

### 两个版本的关系

```
桌面版（电脑）                手机版（iPhone/iPad）
     │                              │
     │  每 20 秒盯盘                 │  随时看、随时改
     │                              │
     └────────► Bark 推送 ◄─────────┘
                     │
                     ▼
              你手机上收到通知
```

**没有桌面版也能用这个手机版** —— 搜索、筛股、看图、记提醒全都正常，
只是不会主动通知你。

## 更新

改了本地文件后，重新上传覆盖同名文件即可。GitHub Pages 一两分钟后自动更新
（手机上可能要下拉刷新一次，或清一下 Safari 缓存）。

## 注意

- 提醒记录存在**你这台设备的浏览器**里。换手机、清缓存会丢，
  重要配置建议用「复制配置」导出备份
- 这个仓库是公开的，**任何人拿到网址都能打开这个网页**。
  但网页里不含任何密钥，你的提醒数据也只在你自己设备上
- 图片识别只支持 **PNG** 格式（截图默认就是 PNG）
